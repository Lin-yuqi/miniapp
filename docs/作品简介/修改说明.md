# WeCraft AI 作品简介页修改说明

输出文件位于 `out/`：

- `wecraft_ai_intro_v1.pdf` / `wecraft_ai_intro_v1.png`：正式信息版。
- `wecraft_ai_intro_v2.pdf` / `wecraft_ai_intro_v2.png`：视觉展示版。

可替换素材位于 `assets/`：

- `csu-logo.png`：中南大学官方校徽。
- `ui-main.png`、`ui-desktop.png`、`ui-mobile.png`：UI 截图素材。

如需修改文案、版式或重新生成文件，编辑 `generate_intro_pages.py` 后运行：

```powershell
.\.venv\Scripts\python.exe .\docs\作品简介\generate_intro_pages.py
```

当前页面尺寸均为 920 x 640 px，PDF 页面尺寸也设为 920 x 640。
